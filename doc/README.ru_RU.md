# KreaProducts для Dolibarr ERP/CRM

KreaProducts — это продвинутый модуль управления продуктами для [Dolibarr ERP/CRM](https://www.dolibarr.org). Он расширяет модуль продуктов питательностью, аллергенами, BOM/техническими листами, инвентаризацией и автоматизацией затрат и склада — для предприятий общепита и розницы, которым нужны стабильность, трассируемость и корректный _food cost_.

## Возможности

### Питательность и аллергены

- Таблица питательности с автоматическим расчетом, валидацией и обновлением.
- Распространение питательных веществ между родительскими/дочерними продуктами, включая BOM (MRP) при включении.
- Управление аллергенами с распространением по проценту общего веса и пометкой следов.
- Поддержка не пищевых продуктов (исключены из расчета).

### Структура продуктов и BOM

- Полное дерево продуктов (связи + BOM/MRP, если включено) с иерархической навигацией.
- Детальная визуализация состава продукта (компоненты, количества и субпродукты) с итогами по **себестоимости**.
- Четкое определение связей между продуктами и техническими листами, включая **исходные упаковки** при необходимости.
- Обратный вид (_где используется_): список наборов/технических листов и меню, где товар используется как компонент, позволяя оценить влияние изменений стоимости, замен и нормализации сырья.
- BOM разборки с происхождением и связями, видимыми в техническом листе.
- Автоматический каскадный перерасчет затрат на основе компонентов/технических листов.
- Поддержка вложенных BOM (строки BOM, ссылающиеся на другую BOM) с корректной передачей затрат, питательности и аллергенов.
- Мультикомпания: общие BOM (entity=0) доступны во всех сущностях, приоритет — для BOM текущей сущности при наличии.
- Разборка управляется по продукту через дополнительное поле `kreap_dismantle`.

### Корректные даты склада и инвентаризации (дата счета и дата-значение)

По умолчанию Dolibarr фиксирует многие движения **на дату регистрации/валидации документа в системе** — что может не соответствовать операционной реальности. В средах с частыми закупками это создает отклонения и шум в анализе запасов.

KreaProducts устраняет это ограничение двумя ключевыми автоматизациями:

- **Поступление на склад по дате счета (поставщики):** товары приходуются с **датой счета/датой поступления**, а не датой регистрации документа в Dolibarr. Это устраняет расхождения, когда счет вводится спустя несколько дней.
- **Инвентаризация по дате-значению (задним числом):** корректировка инвентаря применяется по **дате инвентаризации (дате-значению)**, а не по дате подтверждения. Это позволяет вводить инвентаризацию с более ранней датой (например, неделю назад) и сохранять корректность отчетов — то, чего стандартный модуль не гарантирует.
- **Перерасчет по физической инвентаризации:** пересчет запасов использует **подсчитанное количество** (qty_stock), при отсутствии — qty_view как запасной вариант, предотвращая ошибки при задних датах.

### Умное управление упаковками и единичной стоимостью (автоматическая разборка)

В общепите часто покупают один и тот же товар в разных упаковках — но для _food cost_ важна **реальная единичная стоимость** (например, EUR/L, EUR/kg, EUR/шт).

Типичный пример: **масло**. Его покупают в **канистрах 10 л, 5 л, 1 л** или **коробках 12x1 л**. Если такие упаковки попадают в систему как "разные продукты", быстро появляются несоответствия по запасам и стоимости.

KreaProducts решает это через **модуль BOM Dolibarr (списки материалов / техлист - FM)**:

- Настраивается FM для упаковки (например, _канистра 10 л_), задается конверсия в единичный продукт (например, _10x 1 л_).
- После этого при каждом вводе закупки такой упаковки система выполняет **автоматическую разборку** в единичный продукт **без участия пользователя**.

Этот процесс:

- создает соответствующие **складские движения**,
- сохраняет **пропорциональную стоимость** и трассируемость (источник -> назначение),
- и обеспечивает готовность единичного продукта для рецептов, инвентаризации и расчетов маржи.

### Автоматическое обновление затрат и _food cost_ (каскад)

KreaProducts также автоматизирует обновление **себестоимости** и **food cost** для конечных продуктов на основе их технических листов (BOM/FM).

На практике:

- если компонент (например, **масло**) имеет обновленную цену закупки,
- все продукты, использующие этот компонент (например, **картофель фри**), **автоматически пересчитываются**,
- благодаря чему _food cost_ и маржа всегда соответствуют реальности без ручных корректировок.

Эта функция особенно важна в компаниях с большим количеством рецептов и частыми закупками, где даже небольшие изменения стоимости должны немедленно отражаться на конечных продуктах.

### Продуктивность и списки

- Упрощенный список продуктов с возможностью скрывать элементы.
- Симулятор цен (Метрики и Маржа) с тестовым markup.
- Список складских движений по продукту с **общим остатком**.

## Требования

- Dolibarr >= 19
- PHP >= 7.0
- Обязательные модули: Продукты, Склад, Поставщики, BOM/MRP
- Опционально: Партии (productbatch)

## Установка

1. Скопируйте модуль в `custom/kreaproducts`.
2. Включите в Конфигурация -> Модули/Приложения -> KreaProducts.
3. Настройте параметры на странице конфигурации.
4. При необходимости импортируйте скрипты из `sql/`.

## Конфигурация (основные константы)

| Константа | Описание |
| --- | --- |
| `KREAPRODUCTS_DEFAULT_WEIGHT_LABEL` | Класс единиц веса. |
| `KREAPRODUCTS_NUTRITIONAL_TABLE_TAB` | Показывать таблицу питательности на вкладке техлиста. |
| `KREAPRODUCTS_ENABLE_COPY_AVG_TO_PRODUCT` | Показывать выбор и кнопку для копирования средних значений на 100 г. |
| `KREAPRODUCTS_ENABLE_COPY_ALLERGENS_TO_PRODUCT` | Показывать выбор и кнопку для копирования аллергенов в другой продукт. |
| `KREAPRODUCTS_AUTO_SYNCH_BUY_PRICE` | Автоматически распространять себестоимость (каскадный пересчет). |
| `KREAPRODUCTS_ALLERGEN_FULL_THRESHOLD_PCT` | Процент общего веса для учета аллергенов как присутствующих. |
| `KREAPRODUCTS_ALLERGEN_TRACE_THRESHOLD_PCT` | Процент общего веса для пометки аллергенов как следов. |
| `KREAPRODUCTS_STOCK_MOVEMENT_DATA` | Использовать дату счета для складских движений. |
| `KREAPRODUCTS_SUPPLIER_MOVE_TIME` | Время для движений по счетам поставщиков. |
| `KREAPRODUCTS_INVENTORY_DEFAULT_TIME` | Время по умолчанию при создании инвентаризации. |
| `KREAPRODUCTS_INVENTORY_CATEGORY_ROOT` | Корневая категория для выбора инвентаря. |
| `KREAPRODUCTS_DISMANTLE_BOMTYPE` | Тип BOM для разборки. |
| `KREAPRODUCTS_DISMANTLE_WAREHOUSE` | Склад для движений разборки. |
| `KREAPRODUCTS_SIM_ENABLE` | Включить симулятор цен. |
| `KREAPRODUCTS_SIM_DEFAULT_MARKUP` | Стандартный markup симулятора. |
| `KREAPRODUCTS_REPLACE_PRODUCT_LIST` | Заменить стандартный список продуктов. |
| `KREAPRODUCTS_DEBUG_LOG` | Включить отладочные логи KreaProducts. |

Примечание: пороги аллергенов — это проценты от общего веса рецепта конечного продукта.

## Права

- Питательность: чтение, запись, удаление.
- Аллергены: чтение, запись, удаление.
- Инвентарь: просмотр ожидаемых значений.
